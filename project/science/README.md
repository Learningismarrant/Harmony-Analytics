## Règle d'utilisation

**Tout changement d'une formule ou d'un coefficient dans `engine/pe_fit/` doit être validé par `head-of-science` en référence à ces documents.**

Si une formule du code diverge de ce qui est documenté ici, le document fait autorité — le code doit être corrigé.
